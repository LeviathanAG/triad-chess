Build fixture
Dockerfile.build uses a pinned official GCC 13 Bookworm compiler stage
and a pinned Python 3.12 slim Bookworm runtime. No compiler is copied into the
runtime. It targets ordinary x86-64, without host-specific instruction flags.
The binary links libstdc++ and libgcc statically, with system glibc dynamically.
The GCC Runtime Library Exception applies to the linked compiler libraries:
https://www.gnu.org/licenses/gcc-exception-3.1.html
